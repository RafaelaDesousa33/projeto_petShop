**PetShop Manager**

Sobre o projeto

O PetShop Manager é um projeto desenvolvido com o objetivo de praticar meus conhecimentos em desenvolvimento web.

A aplicação permite cadastrar pets, selecionar o tipo de animal, escolher serviços de banho e tosa e visualizar o valor total do atendimento.

**Funcionalidades**

Cadastro de pets.
Seleção do tipo de animal (cachorro ou gato).
Seleção de serviços de banho e tosa.
Exibição do resumo do atendimento.
Cálculo do valor total dos serviços.
Tecnologias utilizadas
HTML5
CSS3
JavaScript
Bootstrap 5

**Como executar o projeto**

Faça o download ou clone este repositório.
Abra a pasta do projeto.
Execute o arquivo index.html no navegador.
